# Snake

A small, responsive Snake game that runs in any modern browser. No build step or dependencies required.

## Play

Open `index.html` in a browser, then choose **Start game**.

- Use the arrow keys or **W A S D** to steer.
- Press **Space** to pause.
- On touch screens, swipe on the board or use the direction buttons.
- Your best score is saved in the browser.

## Run locally

You can open the file directly, or serve the folder with any static HTTP server, for example:

```sh
python -m http.server 8000
```

Then visit <http://localhost:8000>.
